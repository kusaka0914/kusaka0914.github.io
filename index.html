PROJECT OVERVIEW

Slime's
Space Travel

C++ / OpenGL個人制作3D Action

球体・楕円惑星を360°移動し、ジャンプ、回避、戦闘、分身を使いながら宇宙を冒険する3Dアクションゲーム。

  • 楕円惑星を360°自由に移動
  • 分身・合体・キャラクター切り替え
  • 2人同時プレイと空中コンボ
  • ステージ作成機能

TECHNICAL HIGHLIGHTS

遊びを支える実装

01

球体・楕円地形への追従

Raycastから足元法線を取得し、地形に沿って重力方向と姿勢を更新。

02

C++ / OpenGL Rendering

描画処理からゲームループまで、3Dゲームの基礎を自作で構築。

03

Bullet Physics

衝突判定、物理挙動、地形とのインタラクションをゲーム体験に接続。

04

ステージエディタ

ImGui / ImGuizmoで選択・複製・削除・3Dプレビューを実装。

05

YAML Hot Reload

パラメータを素早く調整し、プレイフィールの反復改善を支援。
